핀터레스트에서 키워드로 이미지 수집하기 — AI용 절차
================================================================
(다른 AI에게 이 파일을 그대로 프롬프트로 줘서 실행시키면 됨)

목표
----------------------------------------------------------------
주어진 검색 키워드로 핀터레스트를 검색해서, 나온 핀들의 원본(고화질)
이미지 URL을 최대한 많이 수집한다. 개별 핀을 하나씩 클릭할 필요 없음
— 검색 결과 페이지 하나만 읽으면 다 나온다.


전제조건 (중요, 반드시 지킬 것)
----------------------------------------------------------------
- 반드시 로그인된 브라우저 세션으로 접속해야 함. 로그아웃 상태에서는
  핀터레스트가 검색 결과 데이터를 아예 안 줌 — 화면엔 그럴싸하게
  보여도 마케팅용 미리보기일 뿐, 실제 이미지 URL이 페이지 데이터
  안에 없음(직접 확인함).
- 비밀번호를 대신 입력해서 로그인하는 건 하면 안 됨. 이미 로그인되어
  있는 브라우저 세션(사용자의 기존 로그인)을 그대로 사용할 것.
  로그인이 안 되어 있으면 사용자에게 로그인해달라고 요청할 것.


절차
----------------------------------------------------------------
1. https://www.pinterest.com/search/pins/?q=<키워드(URL인코딩)> 로 이동

2. 페이지를 여러 번 스크롤해서 원하는 만큼 결과를 로드한다.
   (스크롤 한 번마다 10~12개 정도씩 추가로 로드됨. 무한 스크롤이라
   원하는 개수가 모일 때까지 반복하면 됨)

3. 아래 자바스크립트를 페이지에서 실행해서 핀 링크 + 원본 이미지
   URL을 한 번에 추출한다 (하나씩 클릭 안 해도 됨 — 이게 핵심):

   const links = [...document.querySelectorAll('a[href*="/pin/"]')];
   const seen = new Set();
   const results = [];
   for (const a of links) {
     const href = a.getAttribute('href');
     if (seen.has(href)) continue;
     seen.add(href);
     const img = a.querySelector('img');
     if (!img || !img.src) continue;
     const original = img.src
       .replace(/\/\d+x\d*\//, '/originals/')
       .replace(/\/\d+x\//, '/originals/');
     results.push({ pin: 'https://www.pinterest.com' + href, original });
   }
   results;

   (핀터레스트 썸네일 URL은 해상도가 경로에 박혀있음 — 예:
   i.pinimg.com/236x/.../파일.jpg. 이 "236x"를 "originals"로 바꾸면
   원본 고화질 파일 URL이 됨. 단, 핀터레스트가 원본을 자체 재호스팅한
   경우에만 작동 — 외부 사이트를 그대로 핫링크한 핀은 이 트릭이 안
   먹혀서 403이 남. 실측 기준 성공률 약 70~80%.)

4. 결과로 나온 original URL들을 이미지 크롤러 앱에 넘긴다. 둘 중
   자신에게 맞는 방법으로:

   [로컬 실행 권한이 있는 AI (예: Claude Code)]
     POST http://127.0.0.1:5000/api/images/download-batch
     Body: {
       "folder": "<원하는 폴더명>",
       "images": [
         {"url": "<original URL>", "title": "<검색 키워드>"},
         ...
       ]
     }
     한 번에 다 보내도 됨. 응답의 succeeded/total로 성공 개수 확인.

   [브라우저 안에서만 도는 AI (로컬에 못 닿는 경우)]
     구글 시트 "submissions" 탭에 각 URL을 새 행으로 추가한다
     (컬럼: id, url, source_page, title, folder, status=pending,
     error, created_at). 로컬에서 도는 워커가 자동으로 주워서
     다운로드까지 처리함. 스프레드시트 접근 권한이 없으면 사용자에게
     시트 링크를 요청할 것.


주의사항
----------------------------------------------------------------
- 핀터레스트에 봇 탐지(Arkose Labs CAPTCHA 스크립트)가 심어져 있음.
  한 세션에서 검색 하나당 수십 장 정도(예: 30~50개) 규모로 하는 게
  안전함. 너무 빠르게 반복 검색하면 막힐 수 있음.
- 다운로드 성공률은 100%가 아니라 70~80%대가 정상임(위 3번 참고).
  실패한 건 대부분 재시도해도 똑같이 실패함 — 원본이 없는 게 원인.
- 검색 결과에는 완전히 무관한 이미지(다른 작품, 팬아트, 굿즈 광고
  등)도 섞여 있을 수 있음. 수집 후 사람이 한 번 훑어보고 거를 필요
  있음 — 이 앱의 "URL 하나 바로 다운로드" 옆 큐 목록 화면에서
  선택적으로 버릴 수 있음.
