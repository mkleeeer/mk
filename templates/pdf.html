PDF 시트 자동 다운로드

PDF 전용 시트 열기 ↗ · A열에 URL을 한 줄씩 입력하면 자동으로 받습니다.

이 컴퓨터에서 앱이 실행되는 동안 10초 간격으로 확인합니다. 저장 폴더 기본값은 PDF이며, 완료 후 시트에 파일명·저장 경로가 표시됩니다.

실패한 행은 I열의 원인을 확인하고 D열(status)을 pending으로 바꾸면 재시도합니다. 중지하면 현재 파일 처리 후 멈춥니다.

파일·설명 페이지·미러 URL 다운로드

페이지에 표시된 다운로드·미러 링크를 최대 4단계 따라갑니다. 실패한 미러는 다음 후보로 넘어갑니다. URL에 MD5가 명시되어 있거나 직접 입력하면 받은 원본과 대조합니다. PDF·EPUB·ZIP·DjVu·이미지를 지원하며, 로그인이나 JavaScript 조작이 필요한 페이지는 자동 처리하지 못할 수 있습니다.

페이지에서 링크 찾기 (Link Gopher)

페이지 안의 모든 링크(<a href>)를 뽑아서 보여줍니다. 자료실처럼 PDF/파일 링크가 잔뜩 있는 페이지에서 하나씩 열어보지 않고 골라서 큐에 넣을 때 씀.
